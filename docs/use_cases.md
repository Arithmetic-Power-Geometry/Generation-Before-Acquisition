# Interpretation and use cases

Generation-before-acquisition applies when an organization can either **use existing measurement capability** or **invest to create/enable new capability**.

Representative settings include:

1. **Scientific instrumentation:** buy more measurements from existing instruments versus add a new diagnostic modality.
2. **Sensor systems:** operate installed sensors versus deploy a new sensor type or location that separates previously confounded states.
3. **Medical diagnostics:** order available tests versus enable a new assay or imaging capability.
4. **Cybersecurity and forensics:** collect more logs from existing telemetry versus deploy a new observation capability.
5. **Industrial monitoring:** sample existing channels more heavily versus instrument a previously unobserved failure mode.
6. **Autonomous systems:** spend sensing effort within the current sensor suite versus generate a new sensing/interaction capability.

The key question is decision-relative: does the added capability merely make an already-resolvable decision cheaper, or does it remove an indistinguishability that prevented exact resolution?
